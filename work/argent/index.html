Ten lines to your first answer.

Send your documents with the question and get back an answer with the page each claim came from.

  • SDKsPython, TypeScript, Go
  • StreamingServer-sent events
  • Rate limitsRaised on request
from argent import Argent

client = Argent()
answer = client.answers.create(
    model="argent-2",
    question="When can we exit without a penalty?",
    documents=["supplier-agreement.pdf"],
    citations=True,
)
print(answer.text)      # 90 days' notice after month 24 [1]
print(answer.sources)   # [page 14, page 2]
